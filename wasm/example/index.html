HtmlSanitizer — running in the browser as WebAssembly

The same pure-Aether sanitizer core the Python, Java, Go and Rust bindings use — compiled to wasm32, ~62 KB.

Why this matters: the sanitizer here is not a JavaScript reimplementation. It is byte-for-byte the same sanitizer core as your backend runs, so what the server strips and what the browser strips cannot diverge.
